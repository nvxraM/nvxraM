# Profile versions

- [Version 1](https://github.com/nvxraM/nvxraM/tree/v1): the minimal orbital light
  sculpture and flowing ribbon. Preserved at tag `v1`, including the final
  removal of the profile's footer links.
- [Version 2](https://github.com/nvxraM/nvxraM/tree/v2): surreal organic forms, a luminous inner strand, and a living
  particle field. The visible profile keeps the same handle and short tagline.

Earlier versions remain available through Git tags; their media is not
duplicated in the current profile. To inspect version 1 without switching the
checkout, use `git show v1:README.md` or open the link above.
